- **赛事主题**：绿色发展：与自然共生
- **赛道**：02 家庭化学品安全
- **出题方**：无毒先锋（Toxics-Free Corps）
- **推荐模型**：Qwen3-VL / Qwen3.5-Omni / Qwen3.7-Plus / Wan2.7 / Fun-ASR / ThinkSound

## 赛道要求

- 拍照识别产品风险
- 化学品数据库匹配
- 家庭档案管理与安全建议

## 出题方背景

无毒先锋是深圳市零废弃环保公益事业发展中心发起的公益行动，核心使命是推动消费品中有害化学物质的管控。已有资产：

| 资产 | 内容 |
|---|---|
| 3021条风险产品数据 | 2019-2021年从市场监管总局、消费者协会、欧洲安全门等渠道收集的不合格产品信息 |
| 独立送检报告 | 定期将市面产品送第三方检测（如11款捏捏乐100%超标、55套美白化妆品全部汞超标） |
| 科普内容库 | 在澎湃新闻持续发布检测报告和科普文章 |
| AI探索经验 | 已尝试用AI识别塑料标识 |
| 在建知识库 | 正在招聘"消费品化学物质安全知识库运维主任" |

## 竞品分析

| 应用 | 覆盖范围 | 核心功能 | 短板 |
|---|---|---|---|
| 美丽修行 | 化妆品 | 成分查询、安全评分、肤质匹配 | 只覆盖化妆品，不覆盖清洁剂/玩具/日用品 |
| 成分喵 | 食品+化妆品 | 成分扫描查询 | 同上，不覆盖家庭化学品 |
| 成分扫描王 | 食品配料表 | 扫配料表识别成分 | 只看配料表，不做风险评估 |

**核心发现**：市面所有成分查询App都集中在化妆品和食品，没有一个覆盖家庭清洁剂、儿童玩具、塑料制品、驱蚊液等日用品。无毒先锋的数据正好填补这个空白。

## 产品定位

> **家庭化学品排雷大挑战**——拍照扫描家里的化学品，发现隐藏的安全"雷点"，生成排雷评分，发起全民挑战。

**宣传口号**："我家到底有多少雷？"

## 核心流程

```
点击"开始挑战"
    ↓
AI引导："拍一张你家最可能有化学品的地方，比如厨房水槽下面、卫生间柜子"
    ↓
用户拍第一张全景照
    ↓
Qwen3-VL分析全景 → 识别画面中有化学品/瓶罐的区域
    ↓
AI引导逐个细拍高风险区域："右边柜子上那几个瓶子，靠近拍一下"
    ↓
用户细拍 → 等待识别（放大镜小人动画+趣味旁白）
    ↓
识别完成 → 安全/踩雷 → 踩雷弹出雷点卡片
    ↓
继续引导细拍下一个区域
    ↓
全部拍完 → 生成排雷评分 + 排雷报告
    ↓
分享卡片："我家排雷82分，你家呢？"→ 全民挑战
```

## 产品特色

### 1. 零门槛启动

- 不填信息，不选房间，点击"开始挑战"直接拍
- AI引导用户拍第一张全景照，基于全景内容智能引导后续细拍

### 2. 先宏观再微观的探案式体验

- 第一张全景照：AI分析哪些区域有化学品/瓶罐
- 引导细拍：只引导拍高风险区域，不浪费时间拍安全物品
- 用户感受：不是在被指令，而是在探索发现

### 3. 等待时间的趣味化——放大镜小人

识别过程需要1-3秒等待，用动画+趣味旁白填充：

- 画面上出现一个拿着放大镜的小人，在物品上查来查去
- 实时显示趣味旁白（LLM生成），例如：
  - "这个成分表字也太小了吧……让我凑近看看……"
  - "嗯，表面活性剂，这个我认识……等等，后面还跟了一个什么？"
  - "让我查查我的数据库……这个组合有点意思……"
  - "叮！找到了。你猜怎么着——"
- 每次旁白不同，用户不会觉得等待无聊，反而期待过程

### 4. 踩雷反馈——有冲击力的雷点卡片

踩雷时弹出卡片，包含：

- 雷点等级（高危/中危/低危）
- 雷点类型（化学品冲突/儿童风险/成分超标/存放不当）
- 雷点说明：具体、有冲击力的文案（不是冷冰冰的"风险等级：高"）
  - 示例："你刚才拍到的84消毒液和这瓶洁厕灵是致命组合。混用会产生氯气——一战时的化学武器。2026年6月就有宝妈因为天天混用进了急诊。"
- 排雷建议：具体的操作建议

### 5. 排雷评分 + 全民挑战

**评分逻辑**：

```
基础分 = 100 -（高危雷数×30 + 中危雷×15 + 低危雷×5）
最低分 = 0分（雷太多）
评分文案示例：
  90-100分："你家比实验室还安全"
  70-89分："基本安全，但有几个角落要收拾了"
  50-69分："隐患不少，建议按排雷报告逐项处理"
  50分以下："你家是化学品雷区，请立即排雷！"
```

**全民挑战传播闭环**：

- 排雷完成 → 生成分享卡片（评分+雷点数+趣味文案）
- 卡片设计精美，一键分享到小红书/朋友圈
- 卡片自带挑战入口："我家排雷82分，你家能拿多少？来挑战→"
- 理想终态：全民晒排雷分数，形成社交传播飞轮

## 技术架构

### 整体调用链路

```
1. 用户拍全景照 → Qwen3-VL分析
   输出：画面中有化学品/瓶罐的区域列表 + 风险预判
   
2. AI引导细拍 → 用户拍近景 → Qwen3-VL识别
   输出：产品品牌/品类/成分表OCR
   
3. 产品匹配 → 风险数据库查询
   
4. 风险评估 → Qwen3.7-Plus推理
   输入：当前产品信息 + 已识别产品列表
   输出：单品风险 + 交叉风险（化学品冲突）
   
5. 识别等待期间 → Qwen3.7-Plus生成趣味旁白
   
6. 全部完成 → Qwen3.7-Plus生成排雷报告
```

### 产品识别（三层降级策略）

| 情况 | AI能识别到什么 | 风险评估方式 |
|---|---|---|
| A. 能看清品牌和品名 | 品牌+品名 → 匹配数据库 | 精确匹配产品风险记录 |
| B. 能看清成分表 | 成分列表 → 匹配成分风险库 | 按成分逐项评估 |
| C. 只能看清品类 | 品类（如"清洁剂"/"驱蚊液"） | 品类通用风险模板 |

### 风险数据库（三层）

**第一层：无毒先锋公开数据（核心壁垒）**

| 数据来源 | 内容 | 获取方式 |
|---|---|---|
| 3021条风险产品抽检信息 | 不合格产品清单 | 无毒先锋澎湃号文章+公开数据集 |
| 独立送检报告 | 具体产品检测数据 | 澎湃新闻文章提取 |
| 科普文章 | 化学品安全知识 | 澎湃新闻爬取+结构化 |

**第二层：公开化学品风险数据库（补充广度）**

| 数据库 | 内容 |
|---|---|
| 国家市场监管总局缺陷产品召回 | 召回产品清单 |
| 欧洲安全门（Safety Gate） | 危险消费品通报 |
| EPA Safer Choice | 化学品安全评级 |
| EWG Skin Deep | 化妆品成分安全评分 |
| 国标GB/T 化妆品安全技术规范 | 限用/禁用成分清单 |

**第三层：化学品冲突规则库（排雷核心）**

这是"雷"的判定基础，是一组规则而非数据：

```
规则示例：
- 次氯酸钠 + 酸性物质 → 产生氯气（剧毒）→ 高危雷
- 含氯漂白剂 + 含氨清洁剂 → 产生氯胺气体 → 高危雷
- DEET（避蚊胺）+ 婴幼儿 → 神经系统风险 → 中危雷
- 邻苯二甲酸酯 + 儿童玩具 → 内分泌干扰 → 中危雷
- 甲醛释放型防腐剂 + 敏感肌 → 过敏风险 → 低危雷
- 同一空间存放不相容化学品 → 潜在反应风险 → 环境雷
```

人工整理50-100条规则覆盖家庭常见场景，LLM基于规则做推理。

### 风险评估引擎

输入：当前产品信息 + 已识别产品列表
推理流程（交给Qwen3.7-Plus）：

```
Step 1：单品风险评估
- 产品本身有没有风险成分？风险等级？

Step 2：交叉风险评估（排雷关键）
- 跟已识别的其他产品有没有冲突？
- 例：已录入84消毒液，现在又拍到洁厕灵 → 触发冲突规则 → "雷！"

Step 3：生成雷点说明
- 具体、有冲击力的文案
- 不是"风险等级：高"，而是真实案例+具体后果
```

### 全景照分析方案

全景照的目标不是精确识别产品，而是**识别哪些区域有化学品**：

```
Qwen3-VL Prompt：
"分析这张家庭场景照片，找出画面中所有可能是化学品/瓶装液体的区域。
对每个区域输出：位置描述、可能是什么品类、风险预判（高/中/低/未知）。
不要识别具体品牌，只需判断品类和位置。"

输出示例：
{
  "区域1": {"位置": "右侧水槽下方柜子", "物品": "多瓶液体容器", "风险预判": "高"},
  "区域2": {"位置": "左侧台面", "物品": "喷雾罐", "风险预判": "中"},
  "区域3": {"位置": "墙角架子上", "物品": "洗衣液瓶", "风险预判": "低"}
}
```

### 放大镜小人动画+趣味旁白

```
识别等待期间（1-3秒）：
1. 前端播放放大镜小人动画（CSS/Lottie动画，小人在物品图上移动）
2. 同时调用Qwen3.7-Plus生成趣味旁白：
   输入：正在识别的物品品类+已识别的物品列表
   输出：2-3句趣味文案，每句0.5秒间隔显示
   
   示例旁白库：
   - "这个成分表字也太小了吧……让我凑近看看……"
   - "嗯，表面活性剂，这个我认识……等等，后面还跟了一个什么？"
   - "让我查查我的数据库……这个组合有点意思……"
   - "叮！找到了。你猜怎么着——"
   - "这个瓶子看起来人畜无害的样子……但我信不过它。"
   - "咦，这个成分我在去年的检测报告里见过……"
```

## 技术栈

| 模块 | 选型 | 说明 |
|---|---|---|
| 前端 | React + Tailwind CSS + Vite | AI辅助生成代码，三个页面足够 |
| 后端 | Python FastAPI | 接收图片→调模型→返回结果 |
| 图像识别 | Qwen3-VL | 全景分析+细拍识别+成分表OCR |
| 风险推理 | Qwen3.7-Plus | 多步推理+趣味旁白生成+报告生成 |
| 语音 | Fun-ASR | 用户可语音交互（可选） |
| 数据库 | 本地知识库+向量检索 | 化学品风险数据结构化存储 |
| 通信 | 普通HTTP请求 | 拍照后POST到后端，等响应返回 |
| 动画 | Lottie / CSS动画 | 放大镜小人动画 |
