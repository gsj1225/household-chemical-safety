# 家庭安全搜索 — User flow

> 版本：v1.0 Draft  
> 日期：2026-08-11  
> 状态：Stage 1 用户流程，待确认

## Goal

让用户通过文字或污渍照片描述家庭清洁任务，系统把结果明确分成两部分：

1. **我家已有产品**：只引用“我的化学品库”中已经登记且用户确认过的产品；
2. **通用处理建议**：不绑定库存，只提供保守的材料处理方法、前置测试和安全边界。

核心承诺：

> 系统先判断问题和风险，再分别回答“我家现有产品里哪些适合”和“没有使用库存产品时可以了解哪些通用方法”，两类建议不能混为一谈。

## Users and scenarios

目标用户是已经在化学品库中登记产品的普通家庭用户，典型场景包括：

- “衣服沾了油污，我家里哪些产品可以尝试？”
- 拍一张衣服上的污渍照片，询问“怎么处理？”
- “浴室水垢怎么处理？我库里有什么合适的产品？”
- “这两个产品能不能连续使用？需要间隔多久？”
- “我家没有合适的产品，应该先补充什么信息或扫描什么产品？”

暂不支持：

- 医疗、皮肤、误食、吸入或中毒处置；
- 工业化学品、实验室试剂和危险品配方；
- 让系统猜测未知成分或绕过产品标签；
- 自动判断用户正在混合、已经混合或已经发生事故。

## Entry points and exits

### Entry points

1. “我的化学品库”主页面进入独立的“安全搜索”模块。
2. 搜索模块支持文字输入和拍照搜索；拍照只用于识别污渍/表面/物品，不直接识别为化学品配方。
3. 产品详情页可进入“针对这件产品提问”，自动带入当前产品上下文，但仍属于安全搜索结果的一种上下文入口。

### Exits

- 查看建议中引用的产品详情；
- 查看相关的相容性关系；
- 返回问答继续追问；
- 返回化学品库；
- 没有合适产品时，进入扫描入库；
- 高风险或超出范围时，返回安全拒答与人工/专业求助提示。

## Current flow (AS-IS)

当前产品能够完成：

1. 用户扫描产品并核对信息；
2. 产品进入“我的化学品库”；
3. 系统根据已确认成分和规则，计算产品之间的相容性关系；
4. 用户查看单个产品详情或全库相容性列表。

当前缺口：用户只能查看已有记录和关系，不能用文字或照片描述“我现在要处理什么”，也不能同时看到库存建议与通用方法的边界。

## Target flow (TO-BE)

```text
进入安全搜索
    ↓
选择输入方式：文字描述 / 拍照识别
    ↓
描述任务：污渍 / 表面 / 目标 / 已知限制
    ↓
系统判断信息是否足够
    ├─ 不足：追问材质、污渍类型、是否已经使用其他产品
    └─ 足够：从库存筛选候选产品
              ↓
        相容性与安全边界校验（仅针对库存候选）
              ├─ 有高风险组合：先展示禁止混用警告，不给混用步骤
              ├─ 有候选产品：放入“我家已有产品”区域
              └─ 无候选产品：明确说明库存中没有合适登记产品
              ↓
        同时生成“通用处理建议”区域
              ├─ 不暗示用户已有该产品
              ├─ 不提供危险配方或混合方法
              └─ 明确标注“仅供参考，先看产品标签并做局部测试”
              ↓
        用户查看两类建议、步骤、注意事项和依据
              ├─ 打开产品详情
              ├─ 查看相容性关系
              ├─ 继续追问
              ├─ 扫描/补充产品
              └─ 返回化学品库
```

## State and action table

| State | Primary action | Secondary action | Failure destination |
|---|---|---|---|
| 初始搜索 | 输入文字或拍摄污渍 | 查看示例问题/拍摄提示 | 保留输入并提示重试 |
| 信息不足 | 补充材质、污渍或已用产品 | 修改原问题 | 回到输入框 |
| 正在分析 | 等待分析完成 | 取消本次搜索 | 返回初始搜索 |
| 有库存候选 | 查看“我家已有产品”步骤 | 打开产品详情/相容性 | 重新搜索 |
| 有通用建议 | 查看“通用处理建议” | 修改材质/污渍信息 | 返回搜索 |
| 候选涉及未知信息 | 补拍或编辑产品信息 | 暂不使用该产品 | 返回问答并标记待补充 |
| 存在禁止混用 | 阅读禁止组合和原因 | 查看关系详情 | 不提供混用步骤，返回问答 |
| 无合适库存 | 查看通用处理建议/扫描添加产品 | 修改任务描述 | 返回初始搜索 |
| 超出安全范围 | 查看拒答原因和求助提示 | 返回化学品库 | 不生成具体化学操作 |
| 网络/API失败 | 重试 | 返回化学品库 | 保留用户问题 |
| 用户离开 | 返回化学品库 | 继续当前搜索 | 草稿是否保留需在 Stage 2 决定 |

## Answer contract and safety rules

每次搜索结果至少包含：

1. 任务理解：系统认为用户要解决什么问题；
2. **我家已有产品**：只能引用库存中已有、信息状态可接受的产品；
3. **通用处理建议**：不声称用户拥有某产品，不替代标签，也不自动转化为库存推荐；
4. 使用步骤：库存产品优先引用产品标签、储存/危险说明和相容性规则；
5. 禁止事项：不能混用的产品、成分或顺序；
6. 先做什么：通风、手套、局部测试、按标签稀释等通用安全措施；
7. 停止条件：出现刺激性气味、变色、发热、身体不适等立即停止并离开现场；
8. 依据与不确定性：哪些来自照片/文字判断、产品标签/规则，哪些仍需用户确认。

硬性安全约束：

- AI 不能直接创建新的化学品或成分，也不能把通用建议伪装成库存产品；
- AI 不能把“未发现已登记禁忌”表达成“绝对安全”；
- AI 不能建议把两个产品混合；
- 相容性引擎优先于语言模型的自由建议；
- 未知成分、未知材质或高风险场景必须降级为追问、拒答或人工求助；
- 所有建议必须可追溯到库存产品、产品字段、相容性规则或明确标注的通用安全原则。

## Product and technical boundary for MVP

MVP 做“库存内安全建议 + 有明确边界的通用处理建议”，不做开放互联网搜索、不做自动购买、不做医疗/事故处置。

- Qwen：负责理解文字/照片中的任务、材质和污渍线索，生成结构化候选意图和可读答案；
- InventoryService：提供当前库存产品和用户确认字段；
- CompatibilityEngine：校验产品组合、禁忌和未知信息；
- 后端安全编排层：过滤不允许的候选、组装证据、输出结构化回答；
- 移动端：展示输入方式、两类结果卡片、产品跳转、相容性跳转和拒答/重试状态。

## UX problems discovered

- 用户知道“要解决什么问题”，但不一定知道产品名称或化学成分；搜索入口应接受文字任务和污渍照片，而不是只接受产品关键词。
- “有什么小技巧”容易诱导 AI 过度发挥，结果必须拆成“我家已有产品”和“通用处理建议”，并分别标注可信边界。
- 清洁建议通常依赖材质、污渍类型和是否已经使用其他产品；缺少这些信息时不能直接给步骤。
- 建议必须区分“可以尝试”“信息不足”和“禁止使用/混用”，不能只返回一段自然语言。
