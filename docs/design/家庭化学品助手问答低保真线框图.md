# 家庭化学品助手问答 — 低保真线框图

> 版本：v2.0 Draft  
> 日期：2026-08-11  
> 阶段：Stage 2，待确认  
> 定位：仓库内置 LLM 助手，不是独立的产品搜索页。

## 1. 产品定位

用户点击“问答”按钮进入助手，在对话中用文字提问或上传照片。LLM 通过后端安全编排层读取：

- 当前用户的已入库产品及确认字段；
- 产品之间的相容性关系；
- 储存条件、危险性、标签警示语；
- 用户当前问题和可选的照片/材质信息。

LLM 输出的是“结合我家仓库的回答”，而不是只做一个通用搜索框。

## 2. 入口

仓库首页头部增加问答按钮：

```text
┌──────────────────────────────────────────┐
│ 我的化学品库                 [问答] [+添加] │
│                              [相容性]      │
└──────────────────────────────────────────┘
```

产品详情页可增加上下文入口：

```text
[问问助手]
已自动带入：威白洁厕灵
```

## 3. 问答首页

```text
┌──────────────────────────────────────────┐
│ ← 返回          家庭化学品助手            │
├──────────────────────────────────────────┤
│ 我可以结合你仓库里的产品，帮你判断安全用法。 │
│                                          │
│ 示例：                                   │
│ [衣服脏了怎么办？] [浴室有水垢怎么办？]   │
│ [这两个产品能一起用吗？]                  │
│                                          │
│ ┌──────────────────────────────────────┐ │
│ │ 输入问题……                         📷 │ │
│ └──────────────────────────────────────┘ │
│                              [发送]      │
└──────────────────────────────────────────┘
```

照片是对话输入的一部分，不单独进入另一个搜索模块。用户可以先拍照，再继续补充文字。

## 4. 对话结果

```text
┌──────────────────────────────────────────┐
│ 你：衣服脏了，有什么办法？                 │
│ 你：📷 污渍照片                            │
├──────────────────────────────────────────┤
│ 助手：                                    │
│ 我看到的是衣物上的疑似油污，但还需要确认   │
│ 面料。你的仓库里目前没有明确适合衣物的产品。 │
│                                          │
│ 【结合我家仓库】                            │
│ • 威白洁厕灵：不建议用于衣物，可能损伤面料  │
│ • 暂无可确认的合适产品                     │
│                       [查看仓库] [相容性]  │
│                                          │
│ 【通用处理建议】                            │
│ • 先用吸水材料轻按，不要反复摩擦            │
│ • 先查看衣物洗涤标签并做局部测试            │
│ • 通用建议不代表你仓库中已有该产品          │
│                                          │
│ 【安全提醒】                                │
│ 不要将不同清洁产品混合使用。                │
└──────────────────────────────────────────┘
```

回答仍然可以分为“结合我家仓库”和“通用处理建议”，但它们都属于同一条 LLM 对话回复，不再拆成独立搜索页面。

## 5. 追问状态

```text
┌──────────────────────────────────────────┐
│ 助手：为了避免损伤衣物，我需要确认：         │
│                                          │
│ 这是棉、化纤还是羊毛面料？                  │
│ [棉] [化纤] [羊毛] [不确定]                 │
│                                          │
│ 你刚才是否已经使用过其他清洁产品？          │
│ [没有] [使用过] [不确定]                    │
└──────────────────────────────────────────┘
```

信息不足时，助手先追问，不直接给出具体化学品步骤。

## 6. 禁止混用状态

```text
┌──────────────────────────────────────────┐
│ 助手：请先不要继续使用这两种产品。           │
│                                          │
│ 已知关系：含氯清洁剂 × 酸性清洁剂            │
│ 风险：可能产生危险气体                      │
│                                          │
│ 系统不会提供混用或连续使用步骤。             │
│ [查看相容性关系] [继续提问]                 │
└──────────────────────────────────────────┘
```

## 7. 无法回答和范围限制

- 产品信息不足：提示补拍、编辑或查看详情；
- 仓库没有合适产品：明确说明“当前库存无法确认”，再给有限的通用建议；
- 涉及误食、中毒、吸入或身体不适：停止具体操作建议，提示联系专业机构；
- 网络失败：保留对话草稿，提供重试；
- LLM 不得编造产品成分、用途或相容性结论。

## 8. 技术边界

```text
移动端问答页
    ↓ 文字 / 照片 / 当前产品上下文
后端安全问答接口
    ├─ InventoryService：读取用户库存
    ├─ CompatibilityEngine：先做禁忌校验
    ├─ LLM：理解问题并组织回答
    └─ SafetyOrchestrator：过滤危险建议、附带证据
    ↓
结构化回复：消息 + 库存产品卡 + 通用建议卡 + 风险卡
```

## 9. Stage 2 确认清单

- [ ] 功能是仓库内置 LLM 助手，通过“问答”按钮进入；
- [ ] 文字和照片都是对话输入，不做独立搜索结果页；
- [ ] 助手读取当前仓库和相容性数据后回答；
- [ ] 回复中区分“结合我家仓库”和“通用处理建议”；
- [ ] 信息不足先追问，高风险先警告，不能让 LLM 自由推荐混合用法；
- [ ] 确认本线框后，再进入 Stage 3 视觉基础、组件映射和 API 契约设计。
