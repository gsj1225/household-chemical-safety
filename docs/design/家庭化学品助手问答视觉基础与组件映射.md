# 家庭化学品助手问答 — 视觉基础与组件映射

> 版本：v1.0 Draft  
> 日期：2026-08-11  
> 阶段：Stage 3，待确认  
> 前置确认：入口为“问答”；形式为 LLM 对话页；支持文字和照片消息；回答结合库存与相容性；区分库存建议和通用建议。

## 1. 视觉定位

问答页沿用现有“黑白灰 + 状态色”的家庭化学品库视觉，不做成彩色聊天软件，也不使用拟人化头像。安全信息优先于 AI 氛围感。

- 页面背景：`semanticColors.surface.page`
- 用户消息：深色实底、浅色文字，表示用户输入；
- 助手消息：`Surface variant="subtle"`，保持长文本可读；
- 库存产品建议：普通信息卡 + 产品风险徽章；
- 通用处理建议：浅灰信息卡，固定显示“非库存推荐”标签；
- 禁止混用：`semanticColors.surface.errorSubtle` + `semanticColors.border.error`；
- 未知/待补充：`semanticColors.surface.warningSubtle` + `semanticColors.border.warning`；
- 发送中/分析中：使用现有 `StateMessage` 或轻量状态行，不新增复杂动画。

## 2. 页面结构

```text
QuestionAnswerScreen
├── HeaderBar                         ← 复用页面标题/返回模式
├── ConversationScroll                ← 对话滚动区
│   ├── UserMessageBubble             ← 文字或照片消息
│   ├── AssistantMessage              ← LLM 文本
│   ├── InventoryAdviceCard           ← 结合我家仓库
│   ├── GeneralAdviceCard             ← 通用处理建议
│   ├── SafetyWarningCard             ← 风险/禁止混用
│   └── ClarificationPrompt           ← 追问按钮组
└── ComposerBar                       ← 文本输入 + 拍照 + 发送
```

## 3. 组件映射

| 问答组件 | 现有组件/令牌 | 新增职责 |
|---|---|---|
| 页面滚动容器 | `ScreenScroll variant="detail"` | 保持键盘和长对话滚动；必要时增加底部安全区 |
| 消息区域 | `Surface`、`typographyTokens.body` | 新建 `AssistantMessage` 和 `UserMessageBubble` |
| 产品建议卡 | `Surface variant="outlined"`、`ProductPhoto`、`SemanticBadge` | 新建 `InventoryAdviceCard`，支持跳转产品详情 |
| 通用建议卡 | `Surface variant="subtle"` | 新建 `GeneralAdviceCard`，固定“非库存推荐”标识 |
| 风险卡 | `StateMessage`、`SemanticBadge tone="critical/attention"` | 新建 `SafetyWarningCard`，支持跳转相容性详情 |
| 追问选项 | `Button`/现有 Pressable 样式 | 新建 `ClarificationPrompt`，44px 最小触摸高度 |
| 文本输入 | `TextInput` 令牌 `componentTokens.input` | 新建 `QuestionComposer`，多行输入、发送禁用态 |
| 拍照入口 | 现有拍照/权限流程 | 复用相机权限和照片资产服务，作为消息附件，不复制识别流程 |
| 加载/错误 | `StateMessage`、`AppDialog` | 复用，不另造错误体系 |

## 4. 消息卡片规则

### 用户消息

- 右侧对齐；
- 文字最多先显示完整内容，不截断；
- 照片显示缩略图和“重新拍摄/删除附件”；
- 不显示化学品风险颜色，避免把用户问题误解为风险结论。

### 助手消息

- 左侧对齐；
- 先显示一句结论，再显示证据和操作建议；
- 长文本分段，不使用一整块无法扫描的段落；
- 回复底部显示“基于库存/相容性/通用原则”的依据标签。

### 库存建议卡

```text
┌──────────────────────────────────────┐
│ 我家已有产品                          │
│ 威白洁厕灵                 [不推荐]   │
│ 不适合衣物，可能造成面料损伤           │
│ [查看产品详情]                         │
└──────────────────────────────────────┘
```

必须使用真实 `productId` 跳转，不能只显示 LLM 返回的产品名称。

### 通用建议卡

```text
┌──────────────────────────────────────┐
│ 通用处理建议       [非库存推荐]        │
│ 先用吸水材料轻按污渍，不要反复摩擦。     │
│ 请以物品标签和材质要求为准。             │
└──────────────────────────────────────┘
```

不能把通用建议渲染成 ProductCard，也不能出现“使用某某库存产品”的按钮。

## 5. 风险优先级

渲染顺序固定为：

1. 禁止混用/高风险警告；
2. 必要追问；
3. 库存产品建议；
4. 通用处理建议；
5. 详情、相容性和继续提问操作。

如果 `CompatibilityEngine` 返回禁止关系，助手文本不能覆盖或弱化风险卡；如果产品字段未知，显示“待补充”，不能显示为安全通过。

## 6. 响应式与交互

- 复用 `ScreenScroll`，键盘弹出时输入栏保持可见；
- 输入框最小高度 48px，多行最大高度建议 120px，超出后内部滚动；
- 拍照按钮和发送按钮均不小于 44px；
- 发送中禁止重复提交，显示轻量“正在结合仓库分析…”；
- 减少动态模式下保留透明度变化，不使用消息气泡缩放动画；
- 页面返回前若有未发送草稿，不弹复杂对话框，默认保留当前会话草稿。
