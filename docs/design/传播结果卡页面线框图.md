## 一、范围与非目标

本线框只确认报告入口、图片卡内容层级、分享/保存动作和必要状态，不改变检查、识别、评分与风险详情流程。

本轮不设计二维码、公开下载页、模板选择、个性编辑、动态卡片和平台专属比例；这些能力必须等真实传播入口和首轮用户反馈后再决定。

## 二、全局布局规则

- 目标设备：Android 390×844；最小验收宽度 320px；Web 最大内容宽度 720px。
- 分享图片：固定 3:4，导出 1080×1440 PNG；预览按容器等比缩放。
- 预览使用全屏模态层而不是跳转新路由，关闭后保留报告滚动与详情状态。
- 模态内容可纵向滚动，底部动作跟随内容，不以绝对定位遮挡卡片。
- 分享卡只使用黑、白、灰与边框层级；不使用红绿风险色。

## 三、动作层级

| 状态 | 主操作 | 次操作 | 安静操作 |
|---|---|---|---|
| 报告页 | 生成结果分享卡 | 查看风险详情 / 检查另一场景 | 无 |
| 卡片预览 | 分享图片 | 保存到相册 | 返回报告 |
| 处理中 | 当前动作显示处理中并禁用全部动作 | 无 | 无 |
| 保存成功 | 分享图片 | 关闭成功提示 | 返回报告 |
| 权限拒绝 / 不支持 | 再试或继续查看 | 返回报告 | 无 |

## 四、页面组

### 01 报告入口

- 目标：在用户完成严肃结论后，把分享作为明确的下一步。
- 信息顺序：评分结论 → 人格标签 → 本轮摘要 → 最高优先级风险 → 分享操作。
- 主操作：“生成结果分享卡”。
- 隐私提示：按钮下说明卡片不含原图、产品名称和家庭地址。

### 02 图片结果卡预览

- 目标：分享前让用户完整确认对外内容。
- 信息顺序：模态标题 → 3:4 卡片 → 隐私说明 → 分享 → 保存 → 返回。
- 卡片顺序：产品名与档案编号 → 场景 → 评分结论 → 人格标签 → 三项统计 → 邀请语 → 安全与隐私边界。
- 主操作：“分享这张图片”。
- 次操作：“保存到相册”。
- 卡片本身不包含按钮和交互状态，保证捕获内容纯净。

### 03 生成、分享与保存状态

- 生成中：主按钮保留尺寸并显示“正在生成图片…”，防止重复捕获。
- 分享不可用：保留预览，解释当前平台只能分享文字摘要。
- 保存权限拒绝：保留预览，明确“只有保存到相册才需要权限”，可再次尝试。
- 保存成功：就近显示“已保存到系统相册”，不弹出遮挡卡片的系统提示。
- 失败：只显示“图片暂时没有生成成功”，不暴露缓存路径、原始异常或平台 API。

### 04 传播图片本体

- 输出尺寸：1080×1440。
- 卡片不读取照片、产品明细、风险来源或 challenge 技术字段。
- 人格文案和邀请语来自受控纯函数，不能由模型临时生成。
- 不出现虚假二维码；公开体验地址准备好后再通过独立配置接入。

## 五、跨页面一致性

| 检查项 | 决策 |
|---|---|
| 视觉语言 | 延续黑白检验档案，不另起彩色社交卡风格 |
| 评分语义 | 继续写“规则评分”，不写检测合格率 |
| 幽默边界 | 只用于人格标签与邀请语，不进入建议和风险事实 |
| 隐私 | 预览所见即分享所得，卡片固定显示隐私声明 |
| 状态反馈 | 文字 + 符号，不使用颜色作为唯一反馈 |
| 可访问性 | 模态打开后播报标题，关闭回到触发按钮；按钮至少 44px |
