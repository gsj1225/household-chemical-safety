## 一、当前状态

旧视觉规范服务于全景 challenge、评分报告和分享卡，不能继续作为 v2 仓库页面的设计权威。新方案保留现有三层令牌思想和高对比基础，但组件语义改为：

- 产品仓库与双列产品卡。
- 产品照片、无图占位和图片丢失。
- 信息核对、日期、标签与来源。
- 相容性列表、关系详情和信息不足。
- 加载、空、错误、权限、保存、退出和删除状态。

本文件已锁定全部视觉决策，包括色彩气质、阴影层次、圆角数值、状态强调、动效原则和图标策略。以下各节为最终规范，不再延后。

## 二、锁定的基础原则

1. 语义优先：页面和组件只使用语义令牌，不直接引用页面名颜色或十六进制值。
2. 状态不依赖颜色：风险、未知、失败、成功和破坏性操作必须同时具备文字与图标/结构。
3. 照片不承载关键文字：仓库摘要放在照片下方，复杂产品图上不直接叠加正文。
4. 未知不等于安全：使用 `unknown`、`needsEvidence`、`noRegisteredConflict`，禁止使用无条件 `safe`。
5. 手机双列：320～520px 内容宽度内固定双列产品卡，文字可增高卡片，不强制等高。
6. 关键操作可触达：所有交互区域至少 44×44；主要按钮视觉高度至少 52。
7. 系统字体与动态字号：不以品牌字体牺牲中文可读性，不用固定高度截断重要安全文字。

## 三、三层令牌模型

### 3.1 原始令牌（Raw tokens）

原始令牌只表达数值，不表达业务含义。建议 TypeScript 顶层保持：

```ts
type RawTokens = {
  palette: {
    neutral: Record<0 | 25 | 50 | 100 | 200 | 300 | 500 | 600 | 700 | 900 | 1000, string>;
    critical: Record<50 | 500 | 700, string>;
    attention: Record<50 | 500 | 700, string>;
    info: Record<50 | 500 | 700, string>;
    positive: Record<50 | 500 | 700, string>;
  };
  space: Record<1 | 2 | 3 | 4 | 5 | 6 | 8 | 10 | 12, number>;
  fontSize: Record<'caption' | 'label' | 'body' | 'titleSmall' | 'title' | 'display', number>;
  lineHeight: Record<'caption' | 'label' | 'body' | 'titleSmall' | 'title' | 'display', number>;
  size: Record<'touchMinimum' | 'inputMinimum' | 'primaryControl', number>;
  duration: Record<'instant' | 'fast' | 'normal', number>;
};
```

锁定数值：

| 类别 | 值 |
|---|---|
| 间距基准 | 4px |
| 常用间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 |
| 最小触控 | 44px |
| 最小输入高度 | 48px |
| 主要控制高度 | 52px |
| 基础正文 | 16px / 24px 行高 |
| 标签 | 14px / 22px 行高 |
| 辅助文字 | 12px / 18px 行高 |

原始颜色为最终确认值（第 11 节已锁定黑白灰体系），不再调整：

```ts

neutral.50   = '#F4F5F7'
neutral.100  = '#E7E9ED'
neutral.200  = '#DDE0E5'
neutral.300  = '#C8CCD3'
neutral.500  = '#686D76'
neutral.600  = '#484C54'
neutral.700  = '#282B30'
neutral.900  = '#08090A'

critical.700 = '#B42318'
attention.700 = '#B54708'
info.700     = '#175CD3'
positive.700 = '#067647'
```

### 3.2 语义令牌（Semantic tokens）

颜色角色：

```ts
semantic.color = {
  surface: {
    page, raised, subtle, sunken, inverse,
    criticalSubtle, attentionSubtle, infoSubtle, positiveSubtle,
    photoFallback, scrim,
  },
  text: {
    primary, secondary, muted, inverse, action,
    critical, attention, info, positive,
  },
  border: {
    default, subtle, strong, focus,
    critical, attention, info, positive,
  },
  action: {
    primary, primaryPressed,
    secondary, secondaryPressed,
    destructive, destructivePressed,
    disabledBackground, disabledForeground,
  },
  status: {
    critical, attention, info, positive, unknown,
  },
};
```

非颜色角色：

```ts
semantic.layout = {
  pageHorizontalPadding,
  pageVerticalGap,
  contentMaxWidth,
  compactGridGap,
  regularGridGap,
  stickyActionInset,
};

semantic.type = {
  display, pageTitle, sectionTitle, cardTitle,
  body, label, caption, metric,
};

semantic.shape = {
  control, card, dialog, pill,
};

semantic.motion = {
  feedback, transition, contentEnter,
};
```

命名约束：

- 禁止 `warehouseBlack`、`riskRed`、`reportCardGray` 等页面或颜色名称。
- 使用 `surface.raised`、`text.critical`、`border.focus` 等职责名称。
- “未命中规则”使用正常文字和结构，不能用绿色独自表达安全。
- `positive` 只表示操作成功或已完成，不表示化学品绝对安全。

### 3.3 组件令牌（Component tokens）

组件令牌只组合语义角色和布局数值，不承载业务判断：

```ts
component.inventoryGrid = {
  columns: 2,
  minCardWidth: 144,
  compactGap: semantic.layout.compactGridGap,
  regularGap: semantic.layout.regularGridGap,
  maxWidth: 520,
};

component.productCard = {
  coverAspectRatio: 3 / 4,
  coverResizeMode: 'contain',
  contentPadding: 12,
  contentGap: 8,
  border: semantic.color.border.default,
  surface: semantic.color.surface.raised,
};

component.productPhoto = {
  detailAspectRatio: 4 / 3,
  fallbackSurface: semantic.color.surface.photoFallback,
  textProtection: 'solid-surface-only',
};

component.field = {
  minHeight: 48,
  multilineMinHeight: 96,
  labelGap: 4,
  contentGap: 8,
};

component.button = {
  minHeight: 52,
  compactMinHeight: 44,
  horizontalPadding: 20,
  contentGap: 8,
};

component.relationshipCard = {
  productPairGap: 12,
  explanationGap: 8,
  emphasisBorderWidth: 2,
};

component.statePanel = {
  contentGap: 12,
  padding: 20,
  actionGap: 8,

```

圆角数值和阴影风格已在第 11 节最终锁定，组件只能引用 `componentTokens.*`，不能在页面内硬编码。

## 四、对比度目标与验证

目标：

- 普通正文和表单标签至少 4.5:1。
- 大文字、图标边界和非文字关键控件至少 3:1。
- 主操作文字、错误文字和危险关系标题优先达到 4.5:1。
- 焦点边框与相邻表面至少 3:1。
- 禁用状态不依赖低对比度传达，必须同时设置不可用语义。

已确认关键组合：

|---|---:|---|
| `#08090A` / `#FFFFFF` | 19.93:1 | AAA |
| `#484C54` / `#FFFFFF` | 8.62:1 | AAA |
| `#686D76` / `#FFFFFF` | 5.20:1 | AA |
| `#686D76` / `#F4F5F7` | 4.77:1 | AA |
| `#B42318` / `#FFFFFF` | 6.57:1 | AA |
| `#B54708` / `#FFFFFF` | 5.43:1 | AA |
| `#175CD3` / `#FFFFFF` | 5.99:1 | AA |
| `#067647` / `#FFFFFF` | 5.69:1 | AA |

最终调色已完成（见第 11 节），以上对比度结果均已验证通过。

## 五、字体与排版

### 系统字体策略

- iOS：系统 San Francisco 中文回退。
- Android：Roboto / Noto Sans CJK 系统回退。
- Web：`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif`。
- MVP 不引入网络字体，避免离线、授权和中文回退问题。

### 字号层级

| 角色 | 字号 / 行高 | 字重 | 用途 |
|---|---:|---:|---|
| display | 32 / 40 | 700 | 空状态或关键结论，低频 |
| pageTitle | 24 / 32 | 700 | 页面主标题 |
| sectionTitle | 20 / 28 | 700 | 详情分区、关系结论 |
| cardTitle | 16 / 24 | 700 | 产品名称、关系卡标题 |
| body | 16 / 24 | 400 | 正文与建议 |
| label | 14 / 22 | 600 | 表单标签、按钮 |
| caption | 12 / 18 | 400 | 来源、更新时间、边界说明 |
| metric | 20 / 28 | 700 | 数量、有效期摘要 |

动态字号规则：

- 关键安全说明不得固定高度或省略为不可恢复的省略号。
- 产品卡名称最多展示两行；完整名称始终可从可访问名称和详情获得。
- 卡片高度允许增长，双列使用瀑布式纵向排列。
- 系统字号放大时，详情和表单必须滚动；底部操作不能覆盖最后一项。

## 六、间距、尺寸和响应式规则

### 手机宽度

| 内容宽度 | 水平边距 | 双列间距 | 单卡最小宽度 |
|---:|---:|---:|---:|
| 320～359 | 12 | 8 | 144 |
| 360～520 | 16 | 12 | 158 |
| >520 | 内容最大宽 520 并居中 | 12 | 保持双列 |

锁定规则：

- “我的化学品库”在手机与宽屏预览中都保持双列，不自动扩展到三列，避免偏离产品方确认的陈列方式。
- 页面内容最大宽度 520；表单、详情和相容性页面共享同一内容宽度。
- 底部导航和粘性操作必须考虑 iOS/Android 安全区。
- 键盘弹出时当前字段滚动到可见区域，保存按钮不能遮挡输入。
- 320×568 等低高度设备允许内容滚动，不压缩触控高度。

## 七、状态语义

所有状态至少由“文字＋图标/结构＋可恢复动作”共同表达：

| 状态 | 标题语义 | 图形/结构 | 必须提供 |
|---|---|---|---|
| critical | 禁止混用/高优先级注意 | 强边框＋警示图标 | 条件、原因、建议、依据 |
| attention | 信息可能影响判断 | 标记＋说明卡 | 补充或确认入口 |
| info | 普通说明/边界 | 信息图标＋辅助面板 | 适用范围 |
| positive | 入库/保存/删除完成 | 完成图标＋完成文字 | 下一步 |
| unknown | 未识别/证据不足 | 未知图标＋占位文本 | 补拍、编辑或保留未知 |
| error | 加载/识别/保存失败 | 错误标题＋原因 | 原地重试与替代路径 |
| destructive | 删除不可逆 | 明确对象与影响 | 二次确认和取消 |
| noRegisteredConflict | 当前规则未命中 | 中性结论卡 | 已检查范围与未知边界 |

禁止：

- 只显示红/黄/绿圆点。
- 使用“安全”“无毒”“合格”作为未命中规则的简称。
- 仅用 Emoji 表达危险等级。
- 把成功入库的绿色与产品安全性混为一谈。

## 八、产品照片与文字可读性

- 仓库卡封面采用 3:4 容器和 `contain`，优先完整显示瓶身，不用 `cover` 裁掉标签。
- 详情封面采用 4:3 容器，可点开查看原缩略图尺寸；MVP 不承诺保留全尺寸原图。
- 图片背景使用中性实底，透明包装或浅色瓶身仍能识别边界。
- 产品名称、日期、储存条件和危险性放在照片下方的实色表面。
- 若必须在图片上显示“照片不可用”等状态，使用不透明实底或高对比标签，不直接压复杂纹理。
- 图片丢失时保留与原容器同等尺寸的占位，减少瀑布流跳动。
- 封面应提供可访问描述，例如“84 消毒液产品封面”；装饰性纹理不朗读。

## 九、动效与减少动态

基础要求：

- 点击反馈 100～140ms。
- 页面/状态过渡 160～220ms，位移不超过 8px。
- 扫描等待允许使用非闪烁的连续进度，但不能暗示已经识别出危险。
- 入库成功和相容性新增只播放一次，不自动循环。
- 产品卡增删重排要保持滚动位置，避免大幅跳动。

系统开启减少动态时：

- 取消扫描线移动、卡片位移、数字滚动和弹性缩放。
- 使用即时状态切换、静态进度图标和文字更新。
- 保留加载中、成功、失败等可访问状态通知。

## 十、当前主题迁移说明

可以保留：

- `rawTokens.space`、字号、行高、最小触控和主要控制高度。
- `semanticColors.surface/text/action/border/status` 的分层思想。
- `AppText`、`AppButton`、`TextField`、`StateMessage` 等基础可访问行为。

需要新增或改名：

- `status.noRuleHit` → `status.noRegisteredConflict`。
- 新增 `status.unknown`、`surface.photoFallback`。
- 新增 `inventoryGrid`、`productCard`、`productPhoto`、`relationshipCard`、`dialog` 和 `bottomNav` 组件令牌。
- `photo.panoramaAspectRatio` 不再是新流程权威；改为仓库封面与详情照片比例。

需要退出新系统权威：

- `analysis` 中的全景区域框和扫描线尺寸。
- `report` 评分环、统计卡和报告摘要。
- `shareCard` 全部令牌。

退出权威不等于本阶段立即删除代码。具体兼容层、迁移顺序和清理时机在实施计划中确定。

## 十一、最终艺术方向（2026-08-03 确认）

### 11.1 色彩情绪与品牌主色

**决策：继续采用黑白灰体系作为品牌主色。**

理由：
- 家庭化学品安全产品的核心交互是"识别风险"，界面框架本身不应与红/黄/绿状态色竞争注意力。
- 黑白灰提供最高对比度（19.93:1），在厨房、储物间等光线不理想的环境中可读性最佳。
- 状态色（critical/attention/info/positive）全部保留用于安全语义，不被品牌色稀释。

最终色板维持现有 `rawTokens.palette` 不变：
- 品牌主色：`neutral.900`（#08090A）——按钮、标题、强调文字
- 品牌浅色：`neutral.50`（#F4F5F7）——Surface subtle 背景
- 状态色：`risk.critical`（#B42318）、`risk.medium`（#B54708）、`info`（#175CD3）、`risk.noRuleHit`（#067647）

### 11.2 图标与插画语言

**决策：文字标签优先，不引入自定义图标集。**

- 风险等级通过 SemanticBadge 的文字前缀表达（× 严重、! 注意、? 未知、· 中性），不依赖图标。
- 状态卡通过顶部强调线 + 文字标题传达严重程度，不需要额外插画。
- 产品照片占位使用虚线框 + 文字"暂无照片"，不使用装饰性插画。
- 系统原生图标仅用于返回按钮（quiet 按钮文字"返回"），不扩展使用范围。

### 11.3 圆角、边框和阴影层次

**圆角最终数值（锁定）：**

| 角色 | 数值 | 令牌 |
|---|---:|---|
| 卡片/对话框/照片 | 12px | `rawTokens.radius.large` → `componentTokens.surface.radius` |
| 输入框 | 10px | `rawTokens.radius.medium` |
| 徽章 | 999 | `rawTokens.radius.round` |
| 小型标签 | 6px | `rawTokens.radius.small` |

**边框性格：**
- 默认边框宽度 1px（`componentTokens.surface.borderWidth`），颜色 `semanticColors.border.default`（#C8CCD3）。
- 照片占位边框 2px 虚线，颜色 `semanticColors.border.default`，比普通边框更明确地表达"缺失"状态。
- 状态强调线宽度 3px（`componentTokens.statusAccent.width`），颜色对应状态色。

**阴影层次（锁定）：**

| 层级 | elevation | shadowOpacity | shadowRadius | 用途 | 令牌 |
|---|---:|---:|---:|---|---|
| 卡片 | 2 | 0.08 | 8 | 产品卡、关系卡 | `componentTokens.elevation.card` |
| 对话框 | 4 | 0.15 | 12 | 模态对话框 | `componentTokens.elevation.dialog` |

阴影色统一使用 `semanticColors.overlay.photo`（rgba(8,9,10,0.58)），偏移均为 {0, height}。

### 11.4 状态强调策略

- **StateMessage**：error 状态使用浅粉背景（`surface.errorSubtle`）+ 红色顶部强调线（3px `status.error`）。
- **StateMessage**：permission 状态使用浅蓝背景（`surface.infoSubtle`）+ 蓝色顶部强调线（3px `status.info`）。
- **AppDialog**：destructive 变体在标题上方显示红色强调线（3px `status.error`）。
- **SemanticBadge**：6 色调（critical/attention/info/positive/unknown/neutral），通过背景色和前缀符号双重表达。
- 状态强调线宽度统一使用 `componentTokens.statusAccent.width`，禁止页面内硬编码。

### 11.5 渐变、纹理和品牌装饰

**决策：不使用渐变、纹理或品牌装饰。**

- 所有 Surface 使用实色背景，不使用渐变。
- 不使用纹理叠加、水印或装饰性分隔线。
- 品牌识别通过排版层级（字重 700/600/400 对比）和留白节奏实现，而非装饰元素。

### 11.6 动效曲线与过渡方式

**最终动效参数（锁定）：**

| 场景 | 时长 | 曲线 | 令牌 |
|---|---:|---|---|
| 点击反馈 | 120ms | ease-out | `rawTokens.duration.fast` |
| 状态切换 | 200ms | ease-in-out | `rawTokens.duration.normal` |
| 扫描等待 | 650ms | linear（连续进度） | `rawTokens.duration.scan` |

**Pressed 反馈参数（锁定）：**
- 常规模式：opacity 0.88 + scale 0.985（`componentTokens.interaction.cardPressed`）
- 减少动态模式：仅 opacity 0.88，无 scale（`componentTokens.interaction.cardPressedReduced`）
- Pressable 反馈为即时样式切换（React Native 原生行为），`rawTokens.duration.fast`（120ms）作为设计参考值，当前未驱动自定义动画时长
- 减少动态状态通过 `useReducedMotion` hook 读取系统设置，由 ProductGrid 统一调用后传入 ProductCard

**减少动态时：**
- 取消 scale 变换，保留 opacity 反馈。
- 扫描等待改为静态进度文字。
- 状态切换改为即时切换，无过渡动画。

### 11.7 产品照片背景风格

**决策：中性实底背景，不使用场景化背景。**

- 仓库卡封面：3:4 容器，`contain` 模式，背景 `surface.subtle`（#F4F5F7）。
- 详情页封面：4:3 容器，`cover` 模式，背景 `surface.subtle`。
- 照片缺失占位：虚线边框 + 文字"暂无照片"，背景 `surface.subtle`，边框 `border.default` 2px。
- 不对产品照片添加品牌水印、圆角遮罩或场景化背景纹理。
