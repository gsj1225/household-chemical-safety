## 范围

- 将单品结果、风险证据和最终报告迁移到黑白风险档案。
- 新增共享 `RiskCard`，统一风险事实、建议、证据和来源。
- 在报告总览加入受控的家庭化学品人格标签和自嘲副标题。
- 保留继续扫描、生成报告、分享、重新挑战和报告缺失恢复行为。

## 非目标

- 不修改评分公式、风险规则、API、Store、报告字段和数据库。
- 不创建分享图片，不携带原图、产品名、地址或其他家庭隐私。
- 不迁移历史列表，不增加 PDF、筛选、折叠或证据抓取。
- 不让幽默文案进入风险事实、处置建议、证据或错误恢复。

## 架构变化

- `RiskCard` 位于组合组件层，只负责结构化风险档案和证据来源链接。
- `ResultView` 负责单品结论、产品摘要、受控副标题和继续动作。
- `ScoreDisplay` 负责评分、人格模板和统计，不重新计算后端评分。
- `MineList` 负责分布与 `RiskCard` 列表，不直接打开除证据来源以外的外部地址。
- `ResultScreen` 继续负责 Store、导航和系统分享。

## 迁移顺序

1. 增加报告与风险档案组件令牌。
2. 新增共享 `RiskCard`。
3. 迁移单品结果和未命中规则状态。
4. 迁移报告评分、人格标签和分布。
5. 迁移雷点列表、零雷点和报告缺失状态。
6. 验证分享、重新挑战、长文本、来源链接和多尺寸滚动。
7. 删除无引用的旧 `MineCard` 与旧页面样式。

## 可访问性检查

- 结果结论、风险等级、证据状态均使用完整文字，不依赖颜色或 Emoji。
- 来源链接暴露按钮角色、组织与标题朗读标签，并保持至少 44px 可点击高度。
- 分享、继续、查看报告、重新挑战按钮保持 52px 或至少 44px。
- 报告缺失和生成中状态具备明确恢复动作与实时状态语义。

## 响应式与平台检查

- 320×568 可纵向滚动到主操作和来源链接，无横向溢出。
- 390×844 验证单品雷点、未命中规则、多雷点报告和零雷点报告。
- 1280×900 内容最大 720px，风险档案不被拉成宽表格。
- 系统分享继续由 React Native `Share` 提供，不增加平台专属依赖。

## 回退策略

- 新旧风险卡在迁移期间可并存；确认无引用后再删除旧组件。
- 页面事件、导航和 Store 数据保持不变，视图可单文件回退。
- 人格标签由纯函数生成，删除不会影响报告和历史数据。

## 功能完成标准

- 单品结果和最终报告与首页、扫描链路属于同一黑白视觉系统。
- “未命中规则”不再表达为绝对安全。
- 风险事实、建议、证据、来源与幽默人格严格分区。
- TypeScript、后端测试、Expo Web 导出和多状态真实浏览器截图通过。

## 交接到后续页面迁移

- 真实页面/状态清单：单品雷点、单品未命中、报告生成、多雷点报告、零雷点报告、报告缺失。
- 仍在使用兼容令牌：历史列表及少量未迁移异常页面。
- 已知视觉不一致：历史页仍使用旧彩色状态和旧卡片。
- 后续切片：历史列表、异常退出与旧主题清理。

## 实施与验证结果

- 新增共享 `RiskCard`，单品结果和报告列表统一使用“等级 → 涉及产品 → 风险事实 → 处置建议 → 证据 → 来源”顺序。
- 单品未命中状态已从“安全”改为“当前规则未发现雷点”，并明确不等于安全证书。
- 报告总览已删除红绿评分圈、彩色圆点和 Emoji，改为黑白评分档案、风险统计和受控人格标签。
- 人格模板只根据评分和雷点数量选择固定文案，不进入风险判断、Store、后端报告或分享文本。
- 多雷点报告、零雷点报告、长证据标题、无来源和证据待复核状态均完成真实浏览器验证。
- 证据来源链接在 390px 手机下高度 83px，分享与重新检查按钮高度均为 52px。
- TypeScript、Expo Web 导出（539 个模块）和后端 19 项回归测试通过。
- 320×568、390×844、1280×900 无横向溢出和控制台警告；320px 小屏内部滚动可到达全部报告操作。
- 旧 `MineCard` 已确认无引用并删除，迁移页面没有旧主题、硬编码色值、Emoji 或直接触控组件。
- 当前剩余风险是 iOS/Android 系统分享面板、外部证据浏览器回跳和目标真机字体需要最终设备 QA。
- 本切片未提交或推送 GitHub，继续按照重大里程碑集中更新。
