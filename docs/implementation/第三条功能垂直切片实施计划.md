# 家庭化学品排雷大挑战——第三条功能垂直切片实施计划

> 版本：v1.0
> 日期：2026-07-18
> 已批准输入：[用户流程](../product/用户流程.md) · [手机端页面线框图](../design/手机端页面线框图.md) · [移动端视觉规范](../design/移动端视觉规范.md) · [前端组件图与设计令牌映射](../design/前端组件图与设计令牌映射.md)

## 范围

- 将纯白、冷灰、近黑写入原始令牌，建立最终可替换的语义颜色和组件配方。
- 让旧 `colors.ts`、`spacing.ts` 继续提供兼容别名，保护未迁移页面。
- 统一 `AppText`、`AppButton`、`Surface` 的高对比文字、按钮、边框、按压、加载和禁用状态。
- 将 `HomeScreen` 迁移到令牌和基础组件，保留开始挑战、历史导航、开始中和失败提醒行为。
- 将全局导航标题、返回色和背景切换到语义令牌。

## 非目标

- 不修改 API、Zustand、路由、扫描状态机和后端。
- 不迁移扫描页剩余视图、单品结果、报告或历史页面。
- 不增加新依赖、图片素材、人格数据模型或分享卡功能。
- 不冻结未来色板；本切片只保证颜色从令牌统一输出。

## 架构变化

- `tokens.ts` 是新视觉的唯一来源，保持原始令牌、语义令牌、组件配方三层。
- `HomeScreen` 只引用语义令牌和公共基础组件，不引用 `colors.ts`、`spacing.ts`，不写十六进制颜色。
- `colors.ts` 与 `spacing.ts` 是短期兼容适配器；全部页面迁移后删除。
- 首页业务动作仍留在页面控制器，展示结构不读取 Store、不调用额外 API。

## 迁移顺序

1. 更新最终令牌值和旧主题兼容映射。
2. 调整 `AppText`、`AppButton`、`Surface` 的组件配方。
3. 迁移 `HomeScreen` 正常和开始中状态。
4. 切换全局导航颜色。
5. 验证错误提醒、历史入口、手机和宽屏布局。
6. 清理首页旧样式与无引用导入。

## 可访问性检查

- 主按钮和次按钮高度为 52，其他可点击目标不低于 44×44。
- 黑底白字、近黑正文、辅助文字满足 WCAG AA。
- 开始中按钮暴露 `busy` 和 `disabled` 状态并保持文案或加载反馈。
- 标题使用 `header` 语义；步骤编号和内容按阅读顺序排列。
- 不通过颜色或 Emoji 单独表达状态。

## 响应式与平台检查

- 390×844 手机基准中底部操作不被安全区遮挡。
- 320px 级小屏允许纵向滚动，不截断标题和隐私说明。
- Web 内容区最大 720px 并居中，不把手机信息层级拉散。
- iOS、Android 和 Web 均使用系统字体，不新增平台专属依赖。

## 回退策略

- 首页迁移可以单文件回退，不影响 API、Store 和后端记录。
- 旧主题兼容别名在本切片保留；如某个旧页面出现视觉问题，可单独恢复兼容值。
- 不删除旧主题导出，直到全部页面完成迁移和视觉 QA。

## 功能完成标准

- 首页视觉与高对比视觉稿一致，不出现旧橙色、Emoji 和普通阴影。
- 开始挑战、重复点击保护、错误提醒和历史导航行为与迁移前一致。
- TypeScript、后端测试和 Expo Web 导出通过。
- 390×844 和宽屏浏览器截图无溢出、裁切或底部遮挡。

## 交接到后续页面迁移

- 真实页面/状态清单：首页正常、开始中、开始失败。
- 仍在使用兼容令牌：扫描剩余视图、单品结果、报告、历史。
- 已知视觉不一致：旧页面仍有彩色风险卡、Emoji 和较大圆角。
- 仍开放的视觉决策：最终中性色精调、风险详情色值、图标资源与分享卡样式。

## 实施与验证结果

- 最终中性色只从三层令牌输出；首页和全局导航不再直接引用旧颜色、旧间距或十六进制色值。
- 首页已迁移为黑白检验档案结构，并保留开始挑战、重复点击保护、历史入口和失败提醒。
- TypeScript 类型检查、Expo Web 导出和后端 19 项回归测试均通过。
- 320×568、390×844、1280×900 三档浏览器实测无横向溢出和控制台警告；小屏使用内部纵向滚动展示完整操作。
- 两个首页按钮高度均为 52px；390px 手机宽度下按钮宽 350px，320px 小屏下按钮宽 280px。
