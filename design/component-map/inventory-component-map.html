层级：Tokens → Primitives → Composites → Feature Views → Screens / Controllers

1. Screens / Controllers

InventoryScreen

加载、刷新、筛选、导航；不计算规则。

IntakeFlowScreen

照片→识别→核对→重复→保存→成功的有限状态控制器。

ProductDetail / Edit

按 productId 读取；表单和对话框为本地状态。

Compatibility / Detail

展示服务端关系和证据，不在前端推理。

9. Anti-components

× UniversalCard + 多个布尔属性

× Screen 同时处理网络、文件、表单和规则

× ProductCard 读取 API 或计算危险关系

× 临时照片进入长期 store / 导航参数
