07 v1.2 异常恢复迁移切片

先建立错误契约兼容层，再按入口迁移；全景恢复是代表性切片，不一次性重写 ScanScreen。

1错误契约

AppFailure、错误码映射、追踪号和用户文案分离。

2恢复组合

RecoveryPanel、语义令牌、播报和触控测试。

3全景代表切片

首页与全景错误就地恢复，保留并重试原图。

4细拍与确认

保留全景定位、失败细拍、草稿和编辑字段。

5报告恢复

保留确认摘要，只重新生成本场景报告。

6清理与真机 QA

移除旧 Alert，完成异常注入、Android 和截图回归。

08 复用规则

复用以语义、行为和可访问性为依据，不以“看起来差不多”为依据。

应该做

  • 页面持有短期失败与重试上下文
  • 事件使用 onRetrySamePhoto 等语义名称
  • 错误协议、文案和 UI 三层分离
  • 组件通过语义令牌获得外观

不应该做

  • 万能错误页 + 页面布尔属性
  • RecoveryPanel 读取错误码或调用接口
  • 把照片 URI、异常或闭包写入 store
  • 失败后清空草稿、结果或重新识别
