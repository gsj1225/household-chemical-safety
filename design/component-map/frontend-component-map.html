07 复用规则

复用以语义、行为和可访问性为依据，不以“看起来差不多”为依据。

应该做

  • 页面只编排流程与数据
  • 事件使用 onConfirm / onRetry 等语义名称
  • 组件通过语义令牌获得外观
  • 加载、禁用、错误有统一行为

不应该做

  • 万能 Card + 大量布尔属性
  • 允许页面任意传颜色和间距
  • 基础组件读取 store 或调用 API
  • 以 homeOrange、scanShadow 命名令牌
